💡 如何設定系統

歡迎使用！這是一個完全免費且運行在您自己資料庫的應用程式。

  1. 請先前往 Firebase Console 建立專案。
  2. 啟用 Firestore Database 與 Anonymous Authentication (匿名登入)。
  3. 在專案設定中取得網頁應用程式的 firebaseConfig。
  4. 點擊首頁的「設定 Firebase 連線」按鈕，將設定貼入即可啟用所有功能。

✨ 關於 AI 批改：本系統預設支援 Gemini Canvas 免費預覽環境測試！

⚙️ 系統設定

請從您的 Firebase 專案中，複製 firebaseConfig 物件 { 和 } 之間的六行內容 (Key: Value)，貼到下方。請勿貼上大括號 {} 或變數宣告，只需貼上 apiKey: "..." 到 appId: "..." 的內容。

Gemini Canvas 環境可免 Key 直接測試，若在外部部署請切換至自訂模式。
